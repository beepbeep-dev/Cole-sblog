Google's newest AI model is only for cyber defenders, for now

Google launched Gemini 4 Argon, its newest frontier model, built for hard software engineering and security work with a 1-million-token limit. It scored 77.9% on the DeepSWE v1.1 coding benchmark. For now, Google is only giving it to vetted cybersecurity defenders through a program called Fairwind.

Reddit is shutting off RSS and its public API

Reddit will end RSS feeds on November 13 and shut down general public API access by March 2027. It blames automated scraping, since posts written by users have become valuable training data for AI companies. Third-party apps, bots and feed readers that rely on Reddit will be affected.
