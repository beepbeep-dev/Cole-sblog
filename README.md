# coleiscool.com

Cole's blog, hosted on GitHub Pages. The main pages are plain HTML, CSS and JavaScript. Posts are Markdown files in `_posts/` that GitHub Pages turns into pages with Jekyll.

| File | What it is |
| --- | --- |
| `index.html` | About me |
| `numbers.html` | Important numbers in coding |
| `404.html` | Not-found page |
| `assets/style.css` | All styles (colors and spacing are tokens at the top) |
| `assets/site.js` | Animations, phone menu, DEC/HEX/BIN switcher, 32-bit bit toggler |
| `games.html` | Arcade page with all four games |
| `assets/arcade.js` | The games: Flappy Bit, Byte Snake, 2048, Bit Breaker |
| `assets/game.js` | The small Flappy Bit in the corner of each page |
| `posts.html` | List of all posts |
| `_posts/` | One Markdown file per post (written with Pages CMS) |
| `_layouts/` | Shared page template (menu, footer) and the post template |
| `media.html` | Photo and video gallery |
| `_media/` | One file per gallery item (added with Pages CMS) |
| `.pages.yml` | Pages CMS settings |
| `CNAME` | Custom domain for GitHub Pages |

## Writing posts

1. Go to [app.pagescms.org](https://app.pagescms.org) and sign in with GitHub.
2. Open **Cole-sblog**, then **Posts**, then **Add an entry**.
3. Fill in the title, date and post, then click **Save**. It shows up on the site in a minute or two.

## Adding photos and videos

In Pages CMS, open **Media**, click **Add an entry**, upload a photo or video, give it a title, and click **Save**.
